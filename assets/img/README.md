# FreshKampo — Assets / Images

## Imágenes requeridas

Coloca aquí las siguientes imágenes para completar el sitio:

### Hero
- `hero-bg.jpg` — Imagen de fondo del hero (campo / berries). Recomendado: 1920×1080px, WebP optimizado.

### Logos
- `logo.png` — Logo FreshKampo (horizontal, fondo transparente). Recomendado: 200×60px
- `logo-white.png` — Logo FreshKampo blanco para fondo oscuro.
- `favicon.ico` — Favicon del sitio (32×32px)
- `favicon-192.png` — Para PWA manifest (192×192px)
- `favicon-512.png` — Para PWA manifest (512×512px)
- `og-image.jpg` — Open Graph preview image (1200×630px)

### Productos
- `fresa.jpg` — Foto de fresa (400×400px)
- `frambuesa.jpg` — Foto de frambuesa (400×400px)
- `zarzamora.jpg` — Foto de zarzamora (400×400px)
- `arandano.jpg` — Foto de arándano (400×400px)
- `higo.jpg` — Foto de higo (400×400px)
- `aguacate.jpg` — Foto de aguacate (400×400px)
- `esparrago.jpg` — Foto de espárrago (400×400px)

### Certificaciones
- `cert-iso.png` — Logo ISO 9001
- `cert-primus.png` — Logo Primus GFS
- `cert-ifs.png` — Logo IFS
- `cert-usda.png` — Logo USDA Organic
- `cert-eu-organic.png` — Logo EU Organic
- `cert-smeta.png` — Logo SMETA / Sedex

### Clientes (logos en escala de grises)
Logos de los supermercados clientes.

## Recomendaciones
- Usar formato WebP siempre que sea posible
- Optimizar con Squoosh o TinyPNG antes de subir
- Usar `loading="lazy"` en imágenes que no sean above-the-fold
